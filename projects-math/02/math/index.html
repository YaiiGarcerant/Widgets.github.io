Proceso: Aproximación por Rectángulos

El algoritmo toma el intervalo total $[a, b]$ y lo divide en $n$ subintervalos iguales. Para cada subintervalo, se identifica la altura $f(x)$ y se calcula el área del rectángulo:

for (let i = 0; i < n; i++) {
  let base = (xMax - xMin) / n;
  let altura = f(xi);
  areaTotal += base * altura;
}

Nota: Es el método más simple pero genera mayor error por defecto o exceso en las curvas.

Proceso: Refinamiento Trapezoidal

A diferencia de los rectángulos, este método utiliza una interpolación lineal entre dos puntos consecutivos. Esto crea un trapecio cuya área se calcula promediando las alturas:

for (let i = 0; i < n; i++) {
  let h_promedio = (f(xi) + f(xi+1)) / 2;
  areaTotal += base * h_promedio;
}

Nota: Reduce significativamente el error al seguir la pendiente real entre las coordenadas.

1. De la Libreta al Código

Definidas (∫ab)

Calculamos el acumulado exacto entre puntos de control. Es la base para volúmenes y áreas reales en ingeniería.

Indefinidas (∫)

Busca la función primitiva. Vital en motores de videojuegos para predecir trayectorias de partículas físicas.

Trigonométricas

Para funciones cíclicas (Sen/Cos). Esencial en procesamiento de audio y estabilidad de señales Wi-Fi.

Matrices y Gauss

Sistemas lineales para resolver múltiples integrales simultáneas. Clave para tu examen de álgebra lineal.
